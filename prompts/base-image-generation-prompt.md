# Base Prompt — NNPC Presentation Image Generation

Use this prompt as the foundation for every NNPC presentation visual.

## Base Instruction

Create a premium 16:9 presentation visual for NNPC Consulting.

Follow the NNPC presentation design system:

- Style balance: Apple 40%, McKinsey 40%, NVIDIA 20%.
- Use black, white, neutral gray, and restrained NNPC Yellow.
- Maintain generous whitespace and one dominant idea.
- Preserve a clear text-safe area for editable Google Slides text.
- Use architectural alignment, precise geometry, thin lines, and restrained 45-degree cuts.
- Communicate enterprise AI, infrastructure, implementation, and business credibility.
- Keep technology realistic and deployable.
- Do not insert body copy, random letters, fake charts, fake logos, or unreadable interface text.
- Avoid generic blue technology imagery, cyberpunk, neon, excessive hexagons, holograms, gaming aesthetics, and decorative clutter.

## Required Variables

Before generation, define:

- Slide purpose
- Main idea
- Subject or environment
- Light or dark mode
- Preferred text-safe side
- Key visual metaphor
- Intended emotional tone

## Default Output

- 16:9 landscape
- Presentation-grade composition
- No final wording unless explicitly requested
- Clean negative space for manual text placement
- Suitable for insertion as a full-slide image in Google Slides

## Example Request

Create an NNPC cover visual for a Private AI Workstation proposal. Use dark mode. Show a realistic enterprise AI workstation integrated into a clean architectural environment. Keep the left 40% quiet for title text. Use a thin NNPC Yellow alignment line and subtle infrastructure geometry. The image should feel premium, technically credible, and deployable—not futuristic or gaming-oriented.
