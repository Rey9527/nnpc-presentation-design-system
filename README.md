# NNPC Presentation Design System

This repository defines the visual system used to generate NNPC presentation imagery for Google Slides.

## Purpose

The workflow is:

1. Read this design system before creating presentation visuals.
2. Generate 16:9 slide images or backgrounds with ChatGPT.
3. Place the generated images into Google Slides.
4. Add and edit final presentation text manually in Google Slides.

This repository is not a PowerPoint template library. It is the source of truth for NNPC presentation style, composition, image direction, and generation prompts.

## Brand Direction

**Apple 40% + McKinsey 40% + NVIDIA 20%**

- Apple: restraint, whitespace, premium composition.
- McKinsey: business logic, hierarchy, decision-focused storytelling.
- NVIDIA: enterprise AI, infrastructure, technical credibility.

The resulting style must feel distinctly NNPC rather than imitating any one brand.

## Core Brand Colors

- Black: authority, infrastructure, technical depth.
- White: clarity, international character, consulting discipline.
- NNPC Yellow: intelligence, innovation, attention.

Yellow is an accent color, not a dominant background color.

## Repository Structure

- `design-system/`: core visual rules.
- `prompts/`: reusable prompts for slide-image generation.
- `checklists/`: quality-control rules before approval.
- `examples/`: approved visual references added later.

## Primary Rule

> Every slide should communicate one idea with maximum clarity.
