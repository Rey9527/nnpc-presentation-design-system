# 02 — Color and Visual Language

## Core Palette

The presentation system is built around black, white, neutral gray, and NNPC Yellow.

### Black

Use for authority, infrastructure, technical depth, cover pages, section dividers, and final pages.

Recommended digital value: `#111111`.

### White

Use as the primary content background. White space is an active design element and must not automatically be filled.

Recommended digital value: `#FFFFFF`.

### Neutral Gray

Use for secondary text, dividers, diagrams, and supporting information.

Recommended range:

- Dark gray: `#3A3A3A`
- Medium gray: `#777777`
- Light gray: `#E8E8E8`
- Background gray: `#F5F5F3`

### NNPC Yellow

Use for emphasis, navigation, selected data, key numbers, directional lines, and calls to action.

Working value until the official logo color is sampled: `#F2B705`.

This value must be replaced if the official NNPC brand file specifies another yellow.

## Color Ratio

For a complete deck, aim approximately for:

- White and light neutrals: 55–70%
- Black and dark neutrals: 25–40%
- NNPC Yellow: 5–10%

These are visual balance guidelines rather than per-slide quotas.

## Yellow Usage

Yellow may be used for:

- one key number;
- a short underline or accent line;
- one highlighted chart series;
- chapter numbers;
- selected nodes or arrows;
- a concise CTA;
- small icon details.

Yellow should not be used for:

- long paragraphs;
- large body-text areas;
- multiple competing highlights;
- full-slide backgrounds except for rare campaign-specific applications;
- decorative gradients.

## Signature Elements

### Accent Line

A thin yellow line may be used as an NNPC signature. Keep it precise and functional. It may indicate alignment, progression, or emphasis.

### Geometric Cut

Use restrained 45-degree cuts inspired by the logo geometry. Do not repeat them so often that they become decoration.

### Architectural Grid

Layouts should feel modular and engineered. Use clear alignment, controlled spacing, and thin structural lines.

### Connection Motif

Subtle lines or nodes may express connection between nations, systems, data, and operations. Keep opacity low and avoid generic glowing network imagery.

## Prohibited Visual Treatments

- Generic blue technology backgrounds
- Cyberpunk or neon aesthetics
- Full-slide circuit-board patterns
- Excessive hexagons
- Glowing holograms floating above hands
- Gaming-style GPU imagery
- Heavy gradients
- Excessive rounded cards
- More than one dominant accent color
- Decorative elements without communication value
